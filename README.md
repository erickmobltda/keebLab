# KeebLab 🎹

Interactive visual configurator for custom mechanical keyboards. Customize your keyboard layout, keycap colors, and features in real-time.

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/keebLab.git
cd keebLab
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000)

### Build for Production

```bash
npm run build
```

### Deploy to GitHub Pages

```bash
npm run deploy
```

## 📋 Features

- **Layout Selection**: Choose between Avalanche and Sofle keyboard layouts
- **Keycap Customization**: Change colors globally or per-key
- **Feature Toggles**: 
  - Tenting holes
  - Rotary encoders (with position selection)
  - Wired/Wireless
  - LED Display
  - RGB per key
